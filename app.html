Paste text and see what is really in it: hidden characters, direction overrides, lookalike letters, and the exact bytes.

Revealed

Purple: hidden or odd spaces. Red: direction controls, control characters, lone surrogates. Amber: letters from another script inside a Latin word.

Findings

Code points

Direction controls: the nine code points (U+202A to U+202E and U+2066 to U+2069) that the Rust advisory for CVE-2021-42574 says to search for, which can make source code read differently than it compiles. Byte counts follow UTF-8 as encoded by the browser; a lone surrogate counts as the 3-byte replacement character. Scripts and categories come from the browser's Unicode property data. The lookalike list is a small hand-picked set of Cyrillic and Greek letters, not the full Unicode confusables table, so a clean verdict does not prove a string is safe. "Clean it" drops direction controls, control characters, lone surrogates and zero-width characters (it keeps joiners used in emoji sequences), turns odd spaces into plain spaces and normalizes to NFC. Runs in your browser, nothing stored.
